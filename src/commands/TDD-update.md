# TDD-update

Update the appropriate command based on what the human is telling you: $ARGUMENTS.

My OpenCode commands live at `~/.config/opencode/commands/`.

1. Read the appropriate command. If it's unclear which one to update, ask me.
2. Make only the requested changes. Don't rewrite the rest or add extra rules.
3. Briefly tell me what changed and whether you saved it or I need to apply it.

Then give me these three commands:

- /TDD
- /TDD-plan
- /TDD-learn

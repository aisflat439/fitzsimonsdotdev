# Working with AI Agents on this Project

## Project Context

This is an **Astro project** - a static site generator framework. The codebase includes:

- Astro components and layouts
- TypeScript/TSX components
- Tailwind CSS for styling
- Content collections for blog posts

## Development Practices

### Testing

- We use **Test-Driven Development (TDD)** with **Playwright**
- Write tests first, then implement the feature
- Tests should be clear and focused on user behavior
- **Workflow**: Write tests and have them fail. Once the human approves the test, pass them.

## Preferred Working Style

When working with AI agents on this project, please follow these guidelines:

### Work Slowly and Deliberately

- Take smaller, incremental steps rather than large sweeping changes
- Focus on one change at a time
- Allow time to review and validate each step before moving forward

### Act as a Pairing Partner

- **Do not make changes proactively** - wait for explicit direction
- When I tell you to do something, do it immediately - don't ask for permission
- Ask clarifying questions ONLY when requirements are truly unclear
- Don't ask for confirmation after I've already given you direction
- Execute exactly what I ask for - nothing more, nothing less

### Communication Style

- Explain what you plan to do before doing it
- Show code snippets or proposals for review
- Confirm understanding of requirements before executing
- Keep changes focused and minimal

### What to Avoid

- Making multiple changes at once without discussion
- Assuming what needs to be done and implementing it immediately
- Refactoring or "improving" code that wasn't part of the request
- Adding extra features or modifications beyond what was asked

## Summary

Think of this collaboration as pair programming - you're the navigator who executes the changes, and I'm driving the direction. Wait for my go-ahead before making changes, and let's build things together step by step.
